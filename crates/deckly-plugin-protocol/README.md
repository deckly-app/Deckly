# deckly-plugin-protocol

The messages, framing and limits that the [Deckly](https://github.com/deckly-app/Deckly)
plugin host and Deckly plugins share. Pure data and encoding, no I/O.

To write a plugin, use [`deckly-sdk`](https://crates.io/crates/deckly-sdk),
which speaks this protocol for you. The protocol itself is described in the
[SDK book](https://deckly-app.github.io/Deckly/reference/protocol.html).
